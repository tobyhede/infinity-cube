# 06: The Active Graph takes the centre, and lanes alternate outwards from it

**What to build:** Where every Edge between two Resources runs one way, the Active Graph's Edge is drawn on the centre line, anchor to anchor. The other Graphs' Edges alternate outwards from it, one lane apart, starting on the positive side, which until 07 is below an Edge between left and right anchors and to the right of one between top and bottom anchors, each one trim increment shorter than the one before in Graph order. Where a pair has Edges both ways, each direction's first Edge runs half a lane from the centre and the rest run a lane further out each, with the direction whose source sorts first on the negative side, as `issues/02` did. That keeps the bundle drawable until 07 makes the positive side each Edge's own left. Activating another Graph moves its Edge to the centre. An Edge alone in its pair runs anchor to anchor whichever Graph is active. Several Graphs' loops on one Resource nest outwards with the Active Graph's innermost and full length. Colour, opacity, stroke width, paint order and head shapes are unchanged. The whole rule is recorded now, in ADR 0143 and the canvas rendering guide, because every part of it is decided. Spec: `../spec-centre-out-lanes.md`.

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] The lane module ranks each direction of a pair with the Active Graph's Edge first, then Graph order. It places a one-direction pair at 0, +1, −1, +2 … lanes by rank, a two-direction pair at ±(rank + ½) lanes with the direction whose source sorts first negative, and loops at 0, 1, 2 … lanes by rank. Each rank trims one more trim increment of a tenth, capped at three tenths, both new values that replace the flat fifth. It takes the Active Graph, or none, as a required argument.
- [x] Reach is the largest offset magnitude in the pair.
