# 04: Turn single-character shortcuts off

Status: ready-for-agent

ADR 0138, WCAG 2.1.4. Depends on 03.

**What to build.** One switch, "Single-key shortcuts", stored as an override (03). While it is off, the dispatcher answers no binding whose key is a single letter, number, punctuation or symbol character pressed with no modifier but Shift: once `?` is retired (below) that is `C`, `P`, `N` and `S`. Space, the arrows, Enter, F2, Delete, Home and the Page keys are unaffected, because 2.1.4 does not count them as character keys. Space needs saying: in the table its key is `' '`, one character long, so the rule is not a length test. Space is named as exempt.

**The sheet has no single-character key (decided 2026-11-14).** `?` is retired as the sheet's key, so the switch never hides the sheet. The sheet opens from a "Keyboard shortcuts" item in the Command Dock, always shown, and from `Ctrl+/` (`⌘/` on macOS), which 2.1.4 does not cover because it carries a modifier. The binding table, `aria-keyshortcuts`, the tooltips and the sheet's own hint are updated to match, and every test or story that presses `?` presses the new key.

**Done when.** An e2e test opens the sheet from the Dock item and from `Ctrl+/`, and sees `?` open nothing. It turns the switch off, presses `C` and `P` on the canvas and sees nothing happen, presses Space on a focused Resource and sees Full View open, reloads and sees the switch still off, and then turns it back on.
