# Claims checked against code and tests

Every claim ADR 0177 makes, and every PostgreSQL claim in `docs/requirements/storage.md`, checked at `32d316f3` against the code and the tests that run on PostgreSQL. Each is **confirmed** (code and a test hold it), **code only** (the code does it and no test fails if it stops), **imprecise** (true in substance, worded wrongly) or **wrong**.

"Mutant" names a fresh hand mutant in `mutants.md`. A claim a surviving mutant breaks is "code only".

## Where Storage says it

Storage has no PostgreSQL host section. It has "The SQLite host" (ST-126 to ST-128), and its PostgreSQL claims sit in the operations table (`serve --store postgres`), ST-3, ST-10 and ST-120. ADR 0177 is accepted and `python3 scripts/adr_snapshot.py check` lists it as pending, so it binds where the two differ (ADR 0175). This is by design (01 left the fold to the next refresh), but it means a reader of Storage today finds no PostgreSQL protocol, classification, pool or TLS rule there. Ticket 06.
