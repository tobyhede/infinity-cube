# Permissions and requests

For a native action, trace the caller through the bundled [shell UI](../../../../packages/desktop/ui), the invoke handler in [main.rs](../../../../packages/desktop/src-tauri/src/main.rs), the command declarations in [build.rs](../../../../packages/desktop/src-tauri/build.rs) and the [window capabilities](../../../../packages/desktop/src-tauri/capabilities). The home window can request a folder chooser with `open_aggregate`. A `closing-*` window can invoke `answer_closing` for its own question. Inspect every capability matching the caller’s label when changing a grant. Tauri combines permissions from matching capabilities. [Tauri capability reference](https://v2.tauri.app/security/capabilities/)

Space windows reach the Space API and asset store through the custom URI scheme. For a request refusal, start at `admit` in [scheme.rs](../../../../packages/desktop/src-tauri/src/scheme.rs) and [address.rs](../../../../packages/desktop/src-tauri/src/address.rs). Check the requesting window, the Aggregate in the address and, for a mutation, the origin evidence specified in ST-121. Changes to a shell window’s invoke permissions affect a different path.

Use the [scheme tests](../../../../packages/desktop/src-tauri/src/scheme/tests.rs) for window ownership and request admission. A change to a response shared across hosts also belongs in the [wire conformance cases](../../../../crates/http-conformance/src/cases.rs). With the browser build in place, run `cargo test --locked -j 2 -p infinity-cube-desktop scheme`. For live webview evidence, record the engine and platform alongside the observed result.
