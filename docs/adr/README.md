# Decision archive

The ADRs in [archive/](archive/) are **history, not binding**. Their status lines describe decisions at the time they were written.

Today’s binding rules are the seven [requirements documents](../requirements/README.md). Read [CONTEXT.md](../../CONTEXT.md) for names and definitions and [AGENTS.md](../../AGENTS.md) for the task-to-doc table.

A behaviour change updates its requirements document in the same commit. Preserve the archive as historical evidence; it does not override the requirements.
